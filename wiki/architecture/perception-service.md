#### observation_builder.py
*service* — Converts CONFIRMED TrackedObjects into Observations for Layer 3 with stateful debouncing.

ObservationBuilder is the final stage of Layer 2 perception that transforms confirmed tracked objects (from tracker) plus persistence results into Observation instances ready for Layer 3. #### observation_validator.py
*module* — Quality gate filtering observations at Layer 2/Layer 3 boundary before ingestion.

Exports ObservationValidator class that applies four independent validation checks to observations: min_area_fraction (rejects sub-pixel artifacts), min_confidence (rejects low-confidence detections), embedding_norm (rejects degenerate embedding vectors, checks both under-min and over-max), and aspect_ratio (rejects pathological bounding boxes, checks both under-min and over-max). #### persistence_check_service.py
*service* — CANON A.5 boundary enforcement: narrow read-only Layer 2→3 interface for object re-identification via multi-modal matching

PersistenceCheckService implements the sole Layer 2→3 persistence query point, calling only find_nodes_by_embedding() on GraphPersistence to avoid coupling. compute_match_score() combines five scoring signals (embedding cosine similarity, spatial IoU, color histogram Jaccard, bbox size ratio, label raw match) with dynamic weights interpolated between two profiles based on confirmation_count threshold (5=new/spatial-dominant, 10+=known/embedding-dominant). Surprise detection flags when confirmation_count>=5 and embedding_distance exceeds surprise_threshold (Piaget R2). Ambiguous candidates (score >= ambiguity_threshold but < match_threshold) are reported for Layer 3 to handle POSSIBLE_DUPLICATE_OF edges; this service does NOT create them per D-TS-01.

- **Exports:** `PersistenceCheckService`, `compute_match_score`
- **Key constants:** `_NEW_THRESHOLD=5`, `_KNOWN_THRESHOLD=10`, `_NEW_WEIGHTS={spatial:0.50, embedding:0.25, color:0.15, size:0.05, label_raw:0.05}`, `_KNOWN_WEIGHTS={embedding:0.45, color:0.25, spatial:0.15, size:0.10, label_raw:0.05}`
- **Deps:** `cobeing.layer2_perception.config`, `cobeing.layer2_perception.types`, `cobeing.layer3_knowledge.protocols`, `cobeing.shared.observation`
- **Gotchas:** CANON A.5 contract enforced: find_match() calls ONLY find_nodes_by_embedding() on persistence backend; any Layer 3 method addition requires CANON amendment. #### pipeline.py
*service* — Orchestrator for Layer 2 perception pipeline: captures frames, runs detection→tracking→feature extraction→persistence check→observation building→spatial extraction in concurrent asyncio tasks.

PerceptionPipeline is the main class that wires all Layer 2 sub-components (frame source, detector, tracker, feature extractors, persistence check, spatial extractor, session manager) into a single runnable unit. It runs two concurrent asyncio tasks: a capture task that pulls frames from the source into a FrameBuffer at capture rate, and a processing loop that pulls the latest frame at processing_fps and runs the full detection→tracking→feature extraction→persistence→observation→spatial extraction chain. Detection and tracking are CPU-bound and dispatched to thread executor. The pipeline maintains change-detection state (MOG2 warm-up for 30 frames, then optional content-hash gating when _change_detection_enabled=True). All Layer 3 communication flows through injected PersistenceCheck and ObservationSessionManager interfaces (CANON A.5 boundary). Observations and spatial relations are validated and collected into instance lists. Exposes run(), stop(), observations property, spatial_relations property, and get_validation_metrics().

- **Exports:** `PerceptionPipeline`
- **Key constants:** `_WARMUP_FRAMES=30`
- **Deps:** `cobeing.layer2_perception.feature_extraction`, `cobeing.layer2_perception.frame_buffer`, `cobeing.layer2_perception.observation_builder`, `cobeing.layer2_perception.observation_validator`, `cobeing.layer2_perception.protocols`, `cobeing.layer2_perception.spatial_extractor`, `cobeing.layer2_perception.types`, `cobeing.shared.observation`
- **Gotchas:** Change detection infrastructure in place (_change_detection_enabled, _previous_frame_hash, frame_hash MD5) but disabled by default (Phase 1); can be enabled for MOG2-equivalent filtering. #### protocols.py
*component* — Protocol contracts for Layer 2 perception pipeline inter-component communication and Layer 2/3 boundary

Defines four @runtime_checkable protocols: FrameSource (async context manager producing camera frames, blocking I/O on __aenter__ released on __aexit__), ObjectDetector (synchronous CPU-bound YOLO interface with detect(frame) -> list[Detection], dispatched to thread executor by caller), ObjectTracker (synchronous SORT-style tracker with update(detections, frame_id) -> list[TrackedObject] maintaining TENTATIVE/CONFIRMED/LOST/DELETED track states), and PersistenceCheck (CANON A.5 narrow Layer 2->3 boundary with single find_match(observation) -> PersistenceResult|None method for identity resolution without direct graph writes). All protocols enforce structural subtyping at type-check time and runtime via isinstance() checks. Synchronous detectors and trackers avoid leaking event loops into domain logic by having callers wrap calls in loop.run_in_executor(). FrameSource returns None gracefully for transient frame gaps rather than raising.

#### spatial_extractor.py

#### tracker.py
*module* — IoU-based frame-to-frame object tracker with SORT-style state machine for associating detections to tracks.

Implements IoUTracker class that matches detections to existing tracks using Intersection-over-Union (IoU) metric. Tracks progress through states: TENTATIVE (unconfirmed, requires min_confirm_frames=3 consecutive matches) → CONFIRMED (stable) → LOST (unmatched, can recover) → DELETED (exceeded max_lost_frames=15). Core algorithm is a greedy assignment that builds an IoU matrix and iteratively selects highest-scoring track-detection pairs above iou_threshold=0.3. Tracks and DetectionObjects are immutable; returns updated active track list each frame. No external deps beyond stdlib and project types—intentionally avoids numpy/OpenCV.
